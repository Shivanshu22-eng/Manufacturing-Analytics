# Data Schema Reference

This document describes every column generated by `generate_data.py`.
These schemas are the authoritative contract between Phase 1 (data) and Phase 2 (SQL/PostgreSQL).

---

## plants

| Column            | Type      | Notes                           |
|-------------------|-----------|---------------------------------|
| plant_id          | integer   | PK, 1–10                        |
| plant_name        | text      | e.g. "Mumbai Manufacturing Plant"|
| city              | text      | NOT NULL                        |
| state             | text      | NOT NULL                        |
| country           | text      | Always "India"                  |
| capacity          | integer   | Units per day                   |
| established_year  | integer   | 1995–2015                       |
| is_active         | boolean   | Always True in dataset          |
| created_at        | timestamp | Simulation start date           |

---

## machines

| Column                | Type      | Notes                             |
|-----------------------|-----------|-----------------------------------|
| machine_id            | integer   | PK, 1–50                          |
| machine_name          | text      | e.g. "CNC Lathe #001"             |
| machine_type          | text      | One of 10 machine types           |
| plant_id              | integer   | FK → plants.plant_id              |
| model_number          | text      | e.g. "MDL-4521"                   |
| manufacturer          | text      | Faker company name                |
| installation_date     | date      | After plant established_year      |
| last_maintenance_date | date      | Filled from maintenance records   |
| status                | text      | Operational / Under Maintenance / Idle / Decommissioned |
| hourly_capacity       | integer   | Units per hour (20–200)           |
| created_at            | timestamp |                                   |

---

## products

| Column           | Type    | Notes                              |
|------------------|---------|------------------------------------|
| product_id       | integer | PK, 1–100                          |
| product_name     | text    | e.g. "Piston Ring (Standard)"      |
| product_code     | text    | UNIQUE, e.g. "PRD-0001"            |
| category         | text    | One of 10 product categories       |
| unit_of_measure  | text    | Always "Piece"                     |
| unit_cost        | numeric | 50–5000 INR                        |
| selling_price    | numeric | 115–150% of unit_cost              |
| reorder_level    | integer | 50–500 units                       |
| reorder_quantity | integer | 200–2000 units                     |
| weight_kg        | numeric | 0.1–50 kg                          |
| is_active        | boolean | Always True in dataset             |
| created_at       | timestamp |                                  |

---

## production

| Column              | Type      | Notes                                      |
|---------------------|-----------|--------------------------------------------|
| production_id       | integer   | PK                                         |
| machine_id          | integer   | FK → machines.machine_id                   |
| plant_id            | integer   | FK → plants.plant_id (denormalized for perf)|
| product_id          | integer   | FK → products.product_id                   |
| production_date     | date      | Date part of shift_start                   |
| shift_start         | timestamp | Within SIM_START–SIM_END                   |
| shift_duration_min  | integer   | 240–720 minutes (4–12 hours)               |
| planned_quantity    | integer   | machine hourly_capacity × shift_hours      |
| actual_quantity     | integer   | planned × efficiency_factor (50–115%)      |
| efficiency_pct      | numeric   | actual/planned × 100                       |
| downtime_minutes    | integer   | 0–20% of shift duration                    |
| status              | text      | Excellent/Good/Average/Poor                |
| created_at          | timestamp |                                            |

---

## quality_inspections

| Column           | Type      | Notes                                      |
|------------------|-----------|--------------------------------------------|
| inspection_id    | integer   | PK                                         |
| production_id    | integer   | FK → production.production_id              |
| machine_id       | integer   | FK → machines.machine_id (denormalized)    |
| plant_id         | integer   | FK → plants.plant_id (denormalized)        |
| product_id       | integer   | FK → products.product_id (denormalized)    |
| inspection_date  | date      |                                            |
| inspection_time  | timestamp |                                            |
| inspector_name   | text      | Pool of 30 names                           |
| qty_inspected    | integer   | 5–30% of actual_quantity                   |
| qty_passed       | integer   | qty_inspected - qty_defective              |
| qty_defective    | integer   | qty_inspected × defect_rate                |
| defect_rate_pct  | numeric   | 0–20%                                      |
| result           | text      | Passed (≤5% defects) / Failed (>5%)        |
| notes            | text      | Empty in dataset                           |
| created_at       | timestamp |                                            |

---

## defects

| Column              | Type      | Notes                                        |
|---------------------|-----------|----------------------------------------------|
| defect_id           | integer   | PK                                           |
| inspection_id       | integer   | FK → quality_inspections.inspection_id       |
| production_id       | integer   | FK → production.production_id                |
| machine_id          | integer   | FK → machines.machine_id                     |
| plant_id            | integer   | FK → plants.plant_id                         |
| product_id          | integer   | FK → products.product_id                     |
| defect_category     | text      | One of 6 defect categories                   |
| defect_description  | text      | Specific description within category         |
| severity            | text      | Low / Medium / High / Critical               |
| qty_defective       | integer   | Defective units for this defect record       |
| defect_date         | date      |                                              |
| is_resolved         | boolean   | 75% resolved                                 |
| resolution_notes    | text      |                                              |
| created_at          | timestamp |                                              |

---

## maintenance

| Column            | Type      | Notes                                        |
|-------------------|-----------|----------------------------------------------|
| maintenance_id    | integer   | PK                                           |
| machine_id        | integer   | FK → machines.machine_id                     |
| plant_id          | integer   | FK → plants.plant_id (denormalized)          |
| maintenance_type  | text      | One of 5 maintenance types                   |
| description       | text      | Specific maintenance action                  |
| technician_name   | text      | Pool of 20 technicians                       |
| start_datetime    | timestamp |                                              |
| end_datetime      | timestamp | NULL if not completed                        |
| duration_hours    | numeric   | NULL if not completed; 0.5–16 hours          |
| cost              | numeric   | 500–50,000 INR                               |
| is_completed      | boolean   | 95% completed                                |
| parts_replaced    | text      |                                              |
| created_at        | timestamp |                                              |

---

## inventory

| Column            | Type      | Notes                                        |
|-------------------|-----------|----------------------------------------------|
| transaction_id    | integer   | PK                                           |
| product_id        | integer   | FK → products.product_id                     |
| transaction_type  | text      | IN / OUT / ADJUSTMENT / RETURN / SCRAP       |
| quantity          | integer   | Always positive; sign implied by type        |
| transaction_date  | date      |                                              |
| transaction_time  | timestamp |                                              |
| unit_cost         | numeric   | From products table                          |
| reference_doc     | text      | e.g. "REF-12345"                             |
| notes             | text      |                                              |
| current_stock     | integer   | Running stock after transaction              |
| reorder_level     | integer   | Copied from products for alerting            |
| is_below_reorder  | boolean   | current_stock < reorder_level                |
| created_at        | timestamp |                                              |

---

## orders

| Column             | Type      | Notes                                       |
|--------------------|-----------|---------------------------------------------|
| order_id           | integer   | PK                                          |
| order_number       | text      | UNIQUE, e.g. "ORD-2023-00001"               |
| customer_name      | text      | Pool of 50 Faker company names              |
| product_id         | integer   | FK → products.product_id                    |
| quantity_ordered   | integer   | 10–5000 units                               |
| unit_price         | numeric   | From products.selling_price                 |
| total_amount       | numeric   | quantity_ordered × unit_price               |
| order_date         | date      |                                             |
| expected_delivery  | date      | order_date + 7–60 days                      |
| actual_delivery    | date      | NULL unless Completed/Shipped               |
| status             | text      | Pending/Confirmed/In Production/Completed/Shipped/Cancelled |
| priority           | text      | Low / Normal / High / Urgent                |
| notes              | text      |                                             |
| created_at         | timestamp |                                             |
